1. Project Overview
This document is the complete build specification for Danish's WhatsApp AI Secretary Agent. The agent monitors incoming WhatsApp messages from a defined allowlist of contacts. If Danish does not reply within 5 minutes, the agent activates, classifies the message against existing chat history, and sends an appropriate secretary-style reply automatically.
The agent is not a chatbot — it is a personal secretary. Replies are always short, human, and contextually aware. It should be indistinguishable from a real human assistant.
1.1 Core Behaviour
Messages from non-allowlisted contacts are silently ignored
Every incoming message from an allowed contact starts a 5-minute countdown timer
If Danish replies manually within 5 minutes — timer is cancelled, his reply is saved to history
If the timer fires — the agent classifies the message and sends a reply
Voice notes are transcribed via Whisper before processing
Images trigger an instant acknowledgement reply (no timer, no AI)
1.2 Reply Classification Logic
When the 5-minute timer fires, the agent runs through this decision tree:

2. System Architecture
The system runs as a single Node.js process. It uses whatsapp-web.js (Puppeteer-based) to connect to WhatsApp Web, Supabase for persistent chat history, Claude for AI reply generation, and OpenAI Whisper for voice transcription.

4. Database — Supabase
4.1 Schema
Run the following SQL in your Supabase SQL Editor to create the required table:
CREATE TABLE IF NOT EXISTS chat_history (
    id          BIGSERIAL PRIMARY KEY,
    contact_id  TEXT        NOT NULL,
    role        TEXT        NOT NULL CHECK (role IN ('user', 'assistant')),
    content     TEXT        NOT NULL,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_chat_history_contact_created
    ON chat_history (contact_id, created_at DESC);
contact_id format: countrycode+phonenumber@c.us — e.g. 923001234567@c.us. No + sign, no spaces, no dashes.
4.2 Supabase Setup Steps
Create a new Supabase project at supabase.com
Go to Project Settings → API — copy the Project URL and service_role key
Go to SQL Editor → paste and run schema.sql
Paste the URL and key into your .env file

    '923009876543@c.us',   // Contact 1

To find a contact's correct ID: in the running agent, log msg.from when a message arrives — that is the exact string to use.

7. AI Prompt Reference
The agent uses three distinct system prompts depending on the classification result. These are defined in agent.js and can be tuned to match Danish's communication style more closely.
7.1 Context Match — Direct Reply Prompt
Used when: new message relates to existing chat history. Model: claude-opus-4-5. Max tokens: 150.
Key instructions: short and direct (max 2 sentences), match language of incoming message, sound human not robotic, use history for relevant context.
7.2 No Context — Busy Reply Prompt
Used when: message has no relation to history AND contact has not yet received a busy reply. Model: claude-opus-4-5. Max tokens: 150.
Key instructions: holding message under 15 words, sound human, match language. Examples: "Danish is a bit tied up, will get back to you shortly!"
7.3 Follow-up — Gentle Acknowledgement Prompt
Used when: contact messages again after already receiving a busy reply. Model: claude-opus-4-5. Max tokens: 150.
Key instructions: under 10 words, warm acknowledgement, match language. Examples: "Noted! Will pass it along", "Got it, he will check shortly"
7.4 Context Classification (Haiku)
Used for: YES/NO decision on whether new message matches history. Model: claude-haiku-4-5. Max tokens: 10. Cost: ~$0.0001 per check.
Passes last 6 messages from history + new message. Expects only "YES" or "NO" in response. If history is empty, defaults to false (no context match).

9. Future Enhancements
Items not in v1.0 but easy to add:
Import existing WhatsApp chat history
Export chat as .txt from WhatsApp → parse with a one-time import script → bulk insert into Supabase
Dynamic allowlist management
Add/remove contacts via WhatsApp command (!allow, !block) instead of editing config.js
Timer duration control
Make the 5-minute delay configurable per contact or via environment variable
Pausing the agent
WhatsApp command (!pause, !resume) to temporarily disable auto-replies
Read receipts / typing indicator
Send a typing indicator before the reply to feel more human
Multi-language persona tuning
Fine-tune system prompts for Roman Urdu vs English vs formal Urdu separately
n8n logging integration
Forward each agent reply to n8n webhook for dashboarding or notifications
Web dashboard
Simple React UI to view chat history per contact, toggle contacts, review agent replies
